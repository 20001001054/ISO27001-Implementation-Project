# ISO 27001 Implementation & Cyber Risk Assessment

## Overview

This project demonstrates the implementation of an Information Security Management System (ISMS) based on ISO 27001:2022 for a fictional FinTech organization.

## Objectives

- Identify information assets
- Assess cybersecurity risks
- Develop risk treatment plans
- Map controls to ISO 27001 Annex A
- Create governance and compliance documentation

## Frameworks

- ISO 27001:2022
- ISO 27005
- NIST Cybersecurity Framework
- GDPR

## Deliverables

- Company Profile
- ISMS Scope
- Asset Register
- Risk Register
- Risk Treatment Plan
- Statement of Applicability
- Internal Audit Report
- Management Review Report
